# Complejo Deportivo Multidisciplinario

## Introduccion

Este proyecto consiste en el desarrollo de una sistema que permita la gestion que gira en torno a un complejo deportivo multidisciplinario, en el cual se administraran las distintas areas deportivos, instalaciones, equipamientos, reservas, estacionamientos y demas servicios que ofrece el complejo.

El desarrollo se llevará a cabo por etapas, donde cada una de estas etapas incorporará nuevas funcionalidades y contemplará las reglas de negocio necesarias para garantizar el correcto funcionamiento del sistema.

## Alcances del proyecto

- Gestionar de socios y clientes.
- Gestionar instalaciones.
- Gestionar reservas.
- Gestionar estacionamiento
- Gestionar torneos y ligas
- Gestionar escuelas deportivas
- Gestionar programas de recreacion vacacionales

## Tecnologias

- JavaScript
- Node.js + Express
- PostgreSQL + Sequelize
- React.js
